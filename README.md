# Job Lead Scout

## Overview

Job Lead Scout searches legitimate job listings using a user-defined set of parameters. It filters listings by location, salary, and seniority level to identify positions where the user is more likely to qualify. Unlike my previous Job Tracker project, which only stores information manually provided by the user, Job Lead Scout automatically retrieves, stores, and displays job leads through a web-based dashboard. Users can also export the collected leads to a CSV file.

## Planned MVP Features

The following features are planned for the MVP and will be updated as they are completed.

- [ x] Collect job leads from legitimate job-search APIs
- [ x] Store essential information about each lead
- [ x] Prevent duplicate listings from being saved
- [ x] Allow leads to be saved, dismissed, applied to, or archived
- [ x] Display collected leads through a web dashboard
- [ x] Export selected leads to a CSV file
